# WP10 — CI quality gate

`.github/workflows/ci.yml` runs on pull requests and on pushes to `main`, `release/**`, and
`feature/**`. Four jobs; no secrets are referenced in the workflow.

| Job | Does | Fails the build on |
|---|---|---|
| **frontend** | node 24, `npm ci`, lint (if a `lint` script exists — none today, skipped), `vitest run`, `npm run build`, `npm audit --omit=dev --audit-level=high` | test failure, build failure, **high/critical production** vulnerability |
| **backend** | JDK 21, `./mvnw --batch-mode clean test` (uses the committed wrapper — no global Maven), uploads Surefire reports | compile/test failure |
| **migrations** | `docker compose up -d --build postgres backend`, polls `/actuator/health` until UP | a broken/missing Flyway migration (the fresh-DB boot never turns UP) |
| **release-hygiene** | `ops/make-release.sh` + a tracked-secret guard | a tracked secret/signing file, a secret PATTERN in the archive, or a prohibited path (`.env`, node_modules, target, dist, keystores, `.claude`, `*;C`) |

## Maps to the required gate
- clean frontend install ✅ · frontend lint (conditional) ✅ · FE unit/integration tests ✅ ·
  FE production build ✅ · dependency-audit policy ✅
- backend wrapper build ✅ · backend tests ✅ · migration validation ✅ (clean DB boot applies V1–V15)
- archive-hygiene verification ✅ · secret scanning ✅ · generated reports (Surefire artifact) ✅
- Fails on: test failure, build failure, missing/broken migration, prohibited release files,
  high/critical prod vuln, committed `.env`/signing material, lint failure (when configured). ✅
- Optional E2E: documented as a follow-up (WP8) — deterministic services + no prod secrets.
